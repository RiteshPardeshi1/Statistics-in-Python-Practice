# Statistics in Python: Practice Notebook

A practice notebook applying statistics concepts in Python.

## What's Inside

- Statistics concepts worked through in code

## Tech Stack

Python, Pandas, NumPy, Matplotlib, SciPy, Jupyter Notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install jupyter pandas numpy matplotlib scipy`
3. Open the notebook with `jupyter notebook` and run the cells in order
